# example

Example applications and guest-language packages for MuduDB.

- [`mpk/`](mpk/) — guest-SDK example apps that build into `.mpk` packages
  (the Rust examples plus the AssemblyScript / C# / Python / Go / C wallet
  variants), built as a separate consumer
  workspace. See [`mpk/README.md`](mpk/README.md) for the full example list
  and build instructions.
